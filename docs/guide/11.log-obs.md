# 日志插件 log-obs

```json5

{
    "setup": {
        "desc": "log-obs to mysql",
        "error_record": true
    },
    "resource": [
        {
            "id": "id1",
            "desc": "日志监控",
            "type": "obs",
            "user": "",
            "pass": "",
            "host": "",
            "port": "",
            "dsn": ""
        },
        {
            "id": "id2",
            "desc": "mysql服务器",
            "type": "mysql",
            "user": "root",
            "pass": "root",
            "host": "127.0.0.1",
            "port": "3306",
            "dsn": ""
        }
    ],
    "source": [
        {
            "resource_id": "id1",
            "sync_mode": "stream",
            "document_set": {
                "project001": "project001"
            },
            "extra": {
            }
        }
    ],
    "target": [
        {
            "resource_id": "id2",
            "document_set": {
                "project001": "project001.project001_log"
            },
            "extra": {}
        }
    ],
    "pipeline": []
}
```

- 一个project只能出现在一个task的一个source中
- obs作为resource且只能出现在source中,sync_mode模式只支持stream
- option只有insert
- msg的数据结构由log-obs客户端程序格式化
